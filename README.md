📘 AI Data Pipeline Simulator – Mini Project

A Python mini project that simulates how raw numerical data is standardized before being used in machine learning models.
The project demonstrates feature scaling, a core preprocessing step in data pipelines used in real-world AI systems.

🧠 Project Goal

Help beginners understand:

How raw numeric data is generated

How to compute mean and standard deviation for each feature

How to apply standardization

Why ML models require normalized data

🎯 Learning Objectives

By completing this mini project, you will:

Use NumPy for numerical data manipulation

Normalize multi-feature datasets

Apply (x - mean) / std transformation

Understand why gradient-based models prefer standardized data

Print outputs for inspection

🛠️ Features

Generates synthetic dataset: 50 samples × 4 features

Calculates:

Feature-wise mean

Feature-wise standard deviation

Applies standardization (Z-score normalization)

Prints summary statistics

Displays the first 3 normalized rows
